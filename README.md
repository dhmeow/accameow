The ACCA StudyHub website was designed as a futuristic cyberpunk study platform using Claude for development assistance and Vercel for deployment. Claude was used to build and refine the HTML, CSS, and JavaScript, including the animated boot sequence, glitch effects, responsive mobile interface, subject-selection system, resource pages, navigation, and interactive transitions. The website was then connected to a GitHub repository and deployed through Vercel, allowing updates pushed to GitHub to be automatically deployed online. External study materials for MA, FA, and LAW were connected through Proton Drive links, while Google Analytics was added to monitor website usage and visitor activity.
